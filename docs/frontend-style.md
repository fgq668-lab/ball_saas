# 场馆预约与球员约战 SaaS 系统前端风格文档

## 1. 风格定位

系统整体采用“清爽、可信、运动服务型”的视觉风格，不做过度炫酷的体育品牌视觉，也不做传统政企后台风。

目标感受：

```text
用户端：轻松、清楚、好预约、有运动氛围
管理端：稳定、高效、信息清晰、适合长期使用
```

## 2. 设计原则

- 首页直接进入可用功能，不做营销式大首页。
- 用户端优先突出场馆、时间、价格、余位、支付状态。
- 管理端优先突出订单、场地、核销、退款、经营数据。
- 少用大面积渐变、复杂阴影和装饰图形。
- 不使用过度圆角，卡片圆角控制在 6-8px。
- 页面留白充足，但后台表格不做过度留白。
- 状态颜色必须稳定统一，例如成功、待支付、退款中、已取消。
- 所有金额、时间、状态必须清晰可扫读。

## 3. 推荐组件体系

### 3.1 微信小程序

建议优先使用：

```text
TDesign Mini Program
WeUI 基础规范
```

说明：

- TDesign Mini Program 适合构建现代小程序组件，视觉更完整。
- WeUI 接近微信原生体验，适合保持微信生态熟悉感。
- 小程序不建议从零手写所有组件，容易造成交互不一致。

### 3.2 管理后台

建议使用：

```text
Vue 3
Element Plus
Pinia
Vue Router
ECharts
```

说明：

- Element Plus 适合后台表格、表单、弹窗、筛选、分页。
- 后台以效率为主，不追求花哨视觉。
- 图表只用于经营概览，不替代表格和明细。

## 4. 色彩建议

主色建议：

```text
主色：#16A085  清爽运动绿
强调色：#2563EB  稳定蓝，用于链接和辅助动作
成功：#16A34A
警告：#F59E0B
危险：#DC2626
正文：#111827
次级文本：#6B7280
边框：#E5E7EB
页面背景：#F6F8FA
卡片背景：#FFFFFF
```

不建议：

- 大面积紫蓝渐变。
- 大面积深色背景。
- 过多荧光绿。
- 大面积橙色/棕色运动风。

## 5. 字体与排版

小程序：

```text
页面标题：20px / 600
模块标题：16-18px / 600
正文：14-15px
辅助信息：12-13px
按钮文字：14-16px / 500
```

后台：

```text
页面标题：20px / 600
区块标题：16px / 600
表格正文：14px
辅助说明：12px
```

要求：

- 不使用负字间距。
- 不使用随视口变化的字体大小。
- 金额和时间使用更醒目的字重。
- 长文本必须截断或换行，不能挤压按钮和状态标签。

## 6. 小程序页面风格

### 6.1 首页

首页优先展示：

```text
定位城市/附近场馆
搜索入口
运动类型筛选
推荐场馆列表
我的预约入口
约战入口
```

视觉建议：

- 顶部使用白底或浅灰底。
- 搜索框明显，但不做巨大 hero。
- 场馆卡片包含真实场馆图、名称、距离、评分、价格、可订状态。
- 操作按钮使用明确动词，例如“订场”“约战”。

### 6.2 场馆详情页

核心信息：

```text
场馆图片
场馆名称
地址/距离
营业时间
可预约运动类型
场地时间表
退款规则
```

视觉建议：

- 场馆图片真实、明亮，不做过暗蒙层。
- 时间选择区域要像日历/排期表，清楚显示可订、已订、不可订。
- 价格和时间必须同屏可见，减少跳转确认成本。

### 6.3 场地预约页

核心信息：

```text
日期选择
场地选择
时间段选择
价格明细
锁定倒计时
确认支付
```

状态建议：

```text
可订：白底 + 主色边框
已选：主色填充
已订：浅灰不可点
维护：斜纹或警告色浅底
```

### 6.4 约战页

核心信息：

```text
约战时间
场馆/场地
已加入人数
等级要求
发起人
加入按钮
```

MVP 说明：

- 约战基于已预约订单创建。
- 页面不要暗示成员已经完成 AA 支付，AA 支付属于 P1。

## 7. 管理后台风格

### 7.1 布局

建议：

```text
左侧菜单
顶部账号/场馆切换
主内容区
列表 + 筛选 + 操作按钮
详情抽屉或弹窗
```

要求：

- 不做营销式首页。
- 不做大面积装饰卡片。
- 操作入口固定、清楚。
- 表格字段按业务优先级排序。

### 7.2 平台首页

核心指标：

```text
今日订单数
今日支付金额
今日退款金额
入驻场馆数
待审核场馆数
待处理退款数
```

### 7.3 场馆后台首页

核心指标：

```text
今日预约
今日核销
今日收入
场地利用率
待处理退款
即将开场订单
```

## 8. 状态标签规范

订单状态：

```text
待支付：橙色浅底
已预约：蓝色浅底
已核销：绿色浅底
已完成：灰绿色浅底
退款中：黄色浅底
已退款：灰色浅底
已取消：灰色浅底
支付超时：灰色浅底
```

场地状态：

```text
可预约：主色
已预约：灰色
维护中：黄色
停用：红色或灰色
```

## 9. 是否需要继续寻找外部样式

需要找参考，但不建议购买或照搬模板。

建议参考方向：

```text
微信生态组件：WeUI
腾讯体系组件：TDesign Mini Program
后台组件：Element Plus
移动端交互参考：Ant Design Mobile
```

最终视觉应服务业务：

- 小程序像一个可信赖的本地运动预约工具。
- 后台像一个长期使用不累的场馆经营系统。
- 样式干净统一，比“看起来很潮”更重要。
